agentraffic

NAIC 2026 · 3rd ACM SIGCOMM Workshop on Networks for AI Computing

Towards Traffic Modelling of Multi-Agent Systems: The Role of Coordination Topology

Davide Lamagna, Albert Cabellos, Alberto Rodriguez-Natal, Gábor Rétvári, Berta Serracanta

Read the blog post Read the paper View the code

In agentic systems, where several LLM agents work on one task, a single request from a user can turn into dozens of calls to the model server, and the way the agents coordinate decides when those calls arrive. We ran the same tasks on the same model under three coordination patterns (agents taking turns, a star of reviewers, and everyone messaging everyone) and measured the traffic from the application down to the network. Fan-out turns the arrivals into bursts followed by long pauses, Poisson models don't fit, and two patterns with the same average call rate can load the server very differently.

This site has the code, a replay demo and the results. For the story in plain words, start with the blog post.
